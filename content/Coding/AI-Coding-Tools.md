Check out:
- Codeium (Windsurf plugin) — unlimited free inline completions, native Neovim support, zero setup cost.
- Aider — terminal-native agentic coding tool, pairs well with nvim, free if used with a free-tier API key (Gemini or Groq).
- GitHub Copilot Free — 2,000 completions + 50 chat requests/month, works in Neovim, most recruiter-recognized name.
- OpenCode — open-source terminal TUI agentic coding tool, no license cost, LLM API costs separate.
- Continue.dev + Ollama — fully local and offline, completely free including inference, best if you want zero cloud dependency.
- Amazon Q Developer — free for individual/personal use, strongest if you ever touch AWS-based projects.
