## ✒️ -> Scratch Notes
Relational DBs 
- Tables (excel)
- No dupliate primary keys

SQL used to interface between application and DB
- SQL = Structured Query Language

IE:
- `CREATE TABLE Products ( ... )`
- `INSERT INTO Products ( ... )`

Foreign Keys
- RelDBs maintain relations through foreign keys
- Foreign keys MUST refer to primary keys of other tables
	- Enforce reference integrity
- Table can contain one or more foreign keys

Table joins

Java Database Connectivity Interface (JDBC)
- Interfaces for Java to SQL
- `PreparedStatement` API:  create a new query
- `pstmt.executeUpdate()`: execute the update
- `ResultSet`API: retrieve query results
