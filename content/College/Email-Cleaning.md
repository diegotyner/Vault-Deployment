### Overview of using agentic AI
Hi everyone. On Monday, March 30, we will have a special Monday Seminar focused on the new agentic AI tools (e.g., Claude Code) that have recently become available for writing stimulus presentation programs, data analysis scripts, etc. These tools go way beyond what a chatbot like ChatGPT or Gemini can do.

  

Petr Janata has spent considerable time using this approach over the past year, and he will provide an overview of how these tools work, what it takes to use them well, their pros and cons, etc. Kurt Winsler has also been using this approach for the past few months and will be on hand to provide the perspective of a trainee.

  

 This session will be at 3:30 PM in the 267 Cousteau conference room.

  

Here’s a basic overview that I copied from a [web site](https://builtin.com/articles/anthropic-claude-code-tool) about the most popular agentic AI tool, Claude Code:

##### What Is Claude Code? 

Claude Code is essentially a specialized [AI agent](https://builtin.com/articles/ai-agents), or an AI system capable of completing complicated, multi-step tasks without the need for rules or [human intervention](https://builtin.com/articles/human-in-the-loop-evolution). Leveraging [agentic intelligence](https://builtin.com/artificial-intelligence/agentic-ai-vs-automation), it can read an entire codebase and understand the context behind a project on its own. It can then autonomously perform a range of tasks, including: 

- Answering questions about the codebase.
- Making edits across multiple files.
- Creating and running tests.
- Addressing bugs and other errors. 
- Handling complex situations like merge conflicts. 

Anthropic also designed Claude Code to be user-friendly, making it available to developers in Slack, on the web, in [integrated development environments](https://builtin.com/articles/integrated-development-environment) and directly in terminals. This way, users don’t have to switch between different environments, and they can use their preferred [command-line interface](https://builtin.com/software-engineering-perspectives/command-line-interface) tools. 

Although Claude Code was first [unveiled in February 2025](https://www.anthropic.com/news/claude-3-7-sonnet), it didn’t garner widespread attention right away. That’s no longer the case, thanks to the rise of a popular technique that Anthropic aims to perfect: Vibe coding. 

##### What Is Vibe Coding, Again?

[Vibe coding](https://builtin.com/articles/vibe-coding) is when you tell an [AI tool](https://builtin.com/artificial-intelligence/ai-tools) what you want to create in [plain language](https://builtin.com/data-science/introduction-nlp), and then it generates the code for you. Not only does this save users from having to manually write the code, but it also gives those with non-technical backgrounds the ability to build their own [coding projects](https://builtin.com/articles/programming-project-ideas). 

Many tech leaders are excited about the greater accessibility this technique presents, with Meta product manager Zevi Arnovitz likening vibe coding to receiving “[superpowers](https://www.businessinsider.com/meta-product-manager-vibe-coding-superpowers-non-technical-builder-2026-1).” Google CEO Sundar Pichai has [even claimed](https://youtu.be/iFqDyWFuw1c?t=1530) that the practice has made coding more “enjoyable” and “approachable,” enabling businesses to equip entire teams with skills that were once limited to experienced developers. 

Anthropic seems to have recognized vibe coding’s promise as well, doubling down on improvements to Claude Code to ensure [users of all coding levels](https://builtin.com/articles/balancing-code-low-code) can use it to complete even the most challenging tasks.
