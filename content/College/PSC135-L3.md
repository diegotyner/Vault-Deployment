#### Cog Psych
Science of how we think
Internal mental processes, HOW we perceive, think, remember, etc.

Ex:
- Why do we process only a small subset of infos?
- why do we remember/forget things?
- How do we make decisions?

#### Paradigms
##### Letter-matching task (posner and Keele 1986)
Participant shown 2 letters and asked to indicate if they were the same letter
- A-A = Same
- A-a = Same
- A-M = Different
##### Sternberg Task (1975)
Now shown 4 letters at the same time, and asked if a letter was present in set

##### Single vs Double Dissociation
> A single dissociation occurs when we find a case of a lesion in region x resulting in a deficit of function a but not function b. 
> A double dissociation - If we find another case, in which a lesion in region y results in a deficit in function b but not in function a, then we have a double dissociation.
