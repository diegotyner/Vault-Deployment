## ✒️ -> Scratch Notes
### High order funcs:
Functions can be used as arguments

#### mapcar
`(mapcar func arglist1 ... arglistn)`
- Func must take n args
- Func is applied to the ith element of the n list
- List of results is returned

#### maplist
applies the function to whole lists and then successive cdrs

#### reduce
Applies the function of the first two arguments of the sequence, then applies to the next argument until all args have been combined
